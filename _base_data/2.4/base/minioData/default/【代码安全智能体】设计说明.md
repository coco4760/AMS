## 1. 智能体定位
代码安全智能体是一个针对软件源代码安全检测与修复的源代码安全智能专家，旨在提高安全技术人员进行源代码安全检测与修复的效率。该智能体通过智能调用静态检测引擎结合安全大语言模型实现软件源代码缺陷的精确检出，支持以自然语言的方式研判缺陷成因，并提供代码级修复方案。
通过该智能体，安全技术人员可减少繁重冗余的缺陷排查工作，集中精力进行核心、高危风险的修复，快速、精准地进行缺陷研判与修复。
## 2. 核心功能
【代码缺陷检测】针对 Java、C、C++、Python、JavaScript、PHP、Go 等跨语言源代码检测，智能按照 CWE、OWASP 等常见代码检测规范完成代码缺陷检测，并支持不断学习其他代码检测规范，持续增强智能体缺陷检测能力。
【缺陷智能研判】结合程序分析的代码结构化数据以及缺陷相关信息，智能体可以自动按照代码实现与缺陷触发逻辑研判缺陷的真实性并分析缺陷的成因以及修复优先级，便于安全技术人员进行缺陷的排查。
【缺陷智能修复】结合缺陷类似修复经验知识库，智能体可根据缺陷当前代码智能提供代码修复方案，并解释修复原因，辅助安全技术人员快速修复相关缺陷。
【自然语言对话】智能体支持安全技术人员通过自然语言的方式进行代码检索与问答以及缺陷相关知识问答。
## 3. 使用流程
【1】进入代码安全智能体后，通过本地或在线 Git 仓库的方式上传源代码
【2】点击“开始分析”，智能体将自动完成缺陷检测并完成缺陷归类去重
【3】选取缺陷进行“缺陷分析”或“缺陷修复”
【4】选取缺陷或代码文件进行自然语言对话
## 4. 应用场景
【代码审计】
传统代码审计工作，需要安全审计人员具备丰富的代码审计实战经验，同时由于传统的静态代码分析工具有高误报、漏洞的挑战，导致安全审计人员难以快速识别出潜在的安全漏洞、代码质量问题以及不符合编码标准的实践，影响整个代码审计工作的效率
代码安全智能体结合代码审计经验知识库与程序分析技术，可自主实现源代码缺陷检测，智能研判缺陷真实性，并提供代码修复方案，有效减少了安全审计人员繁重冗余的缺陷分析工作，提高代码审计效率。
即将推出：【代码安全检测】
通常在进行软件源代码安全检测时，由于安全测试人员技术经验不同，在实际测试过程中，针对同一测试目标会结合自身经验采取不同的安全测试标准定义缺陷的危害程度、修复必要性以及修复方案，企业内部难以执行统一的安全测试规范，导致软件上线后的安全质量参差不齐。此外，组织内会存在多个代码安全检测工具，往往安全测试人员需要针对每个工具检测结果进行单独研判，加上静态检测工具存在的误报挑战，极大增加了安全测试人员的工作量与实践成本，阻碍软件按期上线。
代码安全智能体通过基于自有的安全检测规范库，结合被测目标自身属性智能制定统一的安全检测规范，可保证安全检测的一致性。同时，代码安全智能体，支持集成多个代码检测引擎，并实现不同引擎检测结果的归类去重，实现多工具结果的统一管理，减少安全测试人员重复分析缺陷的工作量。此外，智能体可智能复制安全测试人员进行缺陷的研判，并提供代码修复方案，可有效降低安全测试人员工作量，让其集中精力处理更复杂、更专业的工作。
## 5. 技术性能
【支持语言】Java、C、C++、Python、JavaScript、PHP、Go 等
【误报/漏报】在业内权威代码缺陷测试集（如 Juliet、QuixBugs、SARD）中，Java\C缺陷检测工具的误报率和漏报率为 10%-20%。
【多引擎集成】支持以通用 API 的形式集成各类代码检测引擎
