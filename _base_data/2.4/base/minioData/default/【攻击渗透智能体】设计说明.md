## 1. 智能体定位
攻击渗透智能体是一个具备情报收集与分析、攻击计划制定、攻击脚本编写的“懂攻防、识代码、会推理”渗透测试专家，旨在提高渗透测试人员的专业素养，辅助突破系统的安全防护手段，并结合实际渗透流程提出切实可行的整改方案。
该智能体依托“安全大语言模型+渗透测试实战经验库+渗透测试工具引擎”的框架，可智能收集目标攻击情报数据，完成渗透路径规划与实施，实现自主可控的智能化渗透测试。
通过该智能体可有效帮助渗透测试人员弥补实战经验不足的挑战，减少其简单、重复的工作，确保能够专注于核心渗透任务。
## 2. 核心功能
【情报智能收集与分析】针对渗透目标自主采集暴露在互联网的业务系统、移动应用、代码、人员等信息，智能分析攻击面风险，辅助规划渗透测试流程。
【渗透路径智能规划辅助】基于渗透实战经验库，结合目标实际攻击暴露风险状态，智能体可智能规划各类风险渗透方案。
【渗透工具自主使用】可通过自主或用户指令两种方式，使用指定渗透测试工具完成模拟攻击，分析攻击结果，提供后续模拟攻击思路。
【自然语言对话】智能体支持渗透测试人员通过自然语言的方式进行渗透知识问答、目标渗透结果查询、渗透指令下发等能力。
## 3. 使用流程
【1】进入“攻击渗透”智能体，输入渗透目标组织名称
【2】智能体将自主完成目标情报收集与初步攻击风险分析
【3】在后续攻击渗透实施过程中，通过自然语言进行攻击脚本编写、攻击工具使用、社工钓鱼材料编写等
## 4. 应用场景
【渗透测试】
传统人工渗透测试过程中，渗透测试人员首先会针对渗透目标从各来源进行情报收集，并依靠自身经验收集数据进行分析，制定渗透测试计划。之后借助各类渗透工具进行漏洞扫描、漏洞利用，完成渗透工作并整理测试报告。渗透测试对测试人员的专业素养要求较高，不仅需要具备丰富的渗透实战经验与安全知识，还要具备强大的技术能力，包括脚本编写、工具使用等。
攻击渗透测试智能体基于自身的渗透测试武器库和渗透测试实战经验库，不仅可以针对渗透目标自主完成情报收集与分析工作，还能根据目标情况辅助规划渗透测试思路，使用各类渗透测试装备一步步完成渗透工作，并总结渗透测试流程，输出渗透测试报告。
