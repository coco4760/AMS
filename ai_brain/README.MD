### /ai_brain 简要说明

> ai_brain 是中台大脑平台（dify），包含所有智能体应用服务、知识库、模型的使用、插件（自定义工具）等

- 本文件下包含 5 个基础容器服务：
    - `api` 后端接口
    - `worker` 后端消费异步队列任务，与 `api` 使用相同的镜像
    - `web` 前端页面
    - `sandbox` 代码执行沙箱
    - `nginx` 网络代理 （注意：从容器挂载出来的配置文件在 `./nginx` 下）
- 正常且完整地运行大脑平台还依赖以下 4 个服务：
    1. `postgresql` pg数据库，保存大脑平台基础业务数据
    2. `redis` 缓存数据库
    3. `qdrant` 向量数据库，保存知识库向量数据
    4. `unstructured` 文档解析工具
- 另外需要将一些数据保存到 `${INSTALL_LOCAL}/ai_brain` 目录下，包括
    1. `app/storage`: 用户上传的文件、解析后的文档片段、密钥文件等
    2. `sandbox`: 代码执行沙箱需要挂载的目录，用于存储依赖包等

- 为保证数据准确和一致，请务必保证以下数据正常：
    1. pg数据
    2. qdrant数据
    3. `app/storage` 下的所有数据
